Convert PDF pages to image files

Select a PDF and choose PNG or JPG as the output format. PNG is useful when you want crisp page images, while JPG can produce smaller files. You can also select the rendering resolution.

Each PDF page becomes a separate image. Tendora packages the images into a ZIP download so you can save them together.

What to know before converting

  • Higher resolution usually creates larger image files.
  • Large PDFs may take longer and use more memory on your device.
  • The output is a set of page images, not an editable text document.

PDF processing takes place in your browser.
