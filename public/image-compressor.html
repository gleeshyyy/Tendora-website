Reduce image file size

Large images can take longer to upload, share or add to documents. Select a JPG, PNG or WebP image, choose an output format and adjust the quality to balance file size and appearance.

You can also enter a target width or height when resizing. The tool preserves the image's aspect ratio when dimensions are adjusted. PNG is lossless, so its quality slider does not apply.

Choosing image compression settings

  • Use JPG or WebP when a smaller photographic image is important.
  • Keep PNG when you need lossless output or transparency.
  • Compare the resulting image before using it in a document or website.
