How to add page numbers to a PDF

Choose a PDF from your device, select where the page numbers should appear, and set the starting number and display format. You can leave the first page unnumbered when it is a cover sheet.

Use a separate downloaded copy so your original document remains unchanged. Check the finished PDF to make sure the numbers are readable and do not cover important content.

PDF page numbering options

  • Place numbers at the top or bottom, left, centre or right.
  • Choose a font size and a plain, “Page 1” or “1 / total” format.
  • Start numbering at a number you choose and optionally skip the first page.
